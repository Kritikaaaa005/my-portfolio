# AI Voice Assistant

A Python-based desktop assistant with a graphical chat interface and voice responses.

## Features
- Interactive graphical interface using Tkinter.
- Voice responses using pyttsx3.
- Greeting and conversational responses.
- Displays current time and date.
- Opens Notepad and Calculator.
- Opens Google in a web browser.
- Opens Spotify and WhatsApp.
- Provides random responses for simple conversations.

## Technologies Used
- Python
- Tkinter
- pyttsx3
- Threading
- Webbrowser
- Random
- Datetime

## Installation

1. Install Python.
2. Install the required library:

   `pip install pyttsx3`

## How to Run

Open the terminal in the project folder and execute:

`python ai.py`

## Project Structure

- `ai.py` – Main assistant application.
- `aiDebug.py` – Voice engine testing script.
- `README.md` – Project documentation.
