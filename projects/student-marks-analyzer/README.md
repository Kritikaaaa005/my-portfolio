# Student Marks Analyzer

A beginner-friendly Python project that calculates a student's total marks, percentage, and grade across subjects.

## Features
- Accepts the student's name.
- Accepts the number of subjects.
- Takes marks for subjects.
- Validates that marks are between 0 and 100.
- Calculates total marks and percentage.
- Assigns a grade based on the percentage.

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Open a terminal in this folder.
3. Run `python main.py`.
